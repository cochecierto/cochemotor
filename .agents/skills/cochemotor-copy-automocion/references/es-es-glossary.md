# Glosario editorial es-ES de CocheMotor

## Términos preferidos

| Preferido | Evitar como término principal |
|---|---|
| coche / vehículo | carro / auto |
| matrícula | placa |
| kilómetros | millas |
| maletero | baúl |
| capó | cofre |
| neumáticos | llantas (cuando se habla del conjunto) |
| correo electrónico | email, salvo en una dirección o marca |
| contraseña | clave |
| iniciar sesión | loguearse |
| municipio | localidad, cuando el campo es administrativo |
| comunidad autónoma | estado / provincia, cuando no corresponda |
| solicitud de comprador | lead |
| vehículos en stock | inventario, si el contexto es B2C |
| distintivo ambiental DGT | etiqueta verde, salvo explicación breve |

## Reglas

- Mantener tildes, eñes y signos de apertura.
- Usar «tú» en producto y «usted» solo cuando una superficie legal lo exija.
- Escribir los botones con verbo: «Publicar coche», «Guardar cambios», «Ver contactos».
- No traducir nombres de marcas, versiones, combustibles oficiales ni URLs.
- Marcar como «No especificado» cualquier dato ausente; no completarlo por inferencia.
