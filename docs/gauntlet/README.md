# Informes Gauntlet

Guardar aquí los informes del flujo completo como `[nombre-de-tarea].md`, a partir de `_template.md`. Un informe debe reflejar evidencia real y la versión exacta revisada. Los cambios posteriores a la revisión requieren actualizar evidencias y dictamen.

El flujo reducido puede registrarse en el PR o commit si deja constancia del alcance, la comprobación pertinente, la evidencia y el resultado.
