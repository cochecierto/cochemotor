# Propuesta de ecosistema profesional

## Principio de producto

El panel debe responder primero a la operación de hoy: qué vehículos hay, qué requiere atención y cuál es el siguiente paso para vender. Las nuevas áreas se presentan como apoyo contextual y no interrumpen el recorrido principal.

## 1. Venta compartida e incentivo de viralización

Después de una venta confirmada, el comprador recibe una tarjeta de entrega con un enlace revocable y un código de recomendación. Puede compartir la ficha de su experiencia o recomendar otro coche del marketplace. El incentivo debe ser crédito de servicio (revisión, cambio de aceite o cuota del profesional), nunca una recompensa por publicar opiniones positivas.

Flujo: entrega confirmada → consentimiento para compartir → enlace con atribución → nuevo contacto cualificado → recompensa solo cuando la operación atribuida se valida. El sistema debe limitar frecuencia, permitir cancelar el enlace y registrar consentimiento y atribución.

## 2. Inventario compartido entre profesionales

Una acción “Buscar en la red” aparece cuando el profesional no tiene una unidad compatible con una solicitud. El sistema consulta solo anuncios publicados y contactos autorizados, aplica precio, kilometraje, combustible, ubicación y DGT, y devuelve coincidencias con el profesional propietario. El propietario decide si comparte el contacto; la plataforma no expone teléfonos automáticamente.

## 3. Espacio Emprendedores

Área de aprendizaje por etapas: alta fiscal y perfil, compra en subasta online, compra a particular, vehículos almacenados durante largo tiempo, documentación, prueba, garantías, protección de datos y cálculo de margen. Cada guía termina con una checklist operativa y enlaza al paso del panel que corresponde. El contenido debe identificar normativa y fecha de revisión; no sustituye asesoramiento jurídico o fiscal.

## 4. Red de talleres y lavaderos colaboradores

Ficha verificable para cada colaborador: servicios, zona, disponibilidad, tiempos orientativos y precio base visible. Paquetes iniciales: revisión de entrega, aceite y filtros, preparación estética y lavado. El profesional solicita presupuesto y acepta condiciones antes de compartir datos del cliente. La monetización puede ser suscripción del colaborador, comisión por servicio confirmado o ficha destacada, siempre separada del ranking de calidad.

## Orden de implementación

1. Mantener la ruta operativa del panel y la tarjeta de siguiente acción.
2. Añadir inventario compartido con consentimiento y filtros server-side.
3. Añadir referidos postventa con atribución y límites antifraude.
4. Publicar Emprendedores como contenido versionado.
5. Activar colaboradores con verificación, precios base y flujo de solicitud.
