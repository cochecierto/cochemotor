 # Repositorio de imagen de marca — CocheMotor

La referencia visual oficial es `cochemotor-brand-master-reference.png`. Incluye el logotipo, versiones para fondo claro y oscuro, paleta, icono y sello CocheMotor Verificado.

## Uso

- Cabecera clara: `cochemotor_wordmark.svg`.
- Cabecera o panel oscuro: `cochemotor_wordmark_white.svg`.
- Confianza: `cochemotor_sello_verificado.png`.
- Redes sociales: `cochemotor-brand-master-reference.png`.

Los nombres y usos deben mantenerse centralizados en `brand-assets.json`.


El coche con check rojo forma parte del logotipo oficial. El pistón no forma parte de la identidad.
