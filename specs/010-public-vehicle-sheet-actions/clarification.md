# Clarificación — Spec 010 Acciones de ficha pública

## Decisiones confirmadas para esta entrega

1. **Compartir con varios canales:** se ofrecerá el menú de compartir del dispositivo, no una conexión/API individual por red. El canal que aparezca depende de las aplicaciones instaladas y del navegador. Copiar enlace será el respaldo universal.
2. **WhatsApp como contacto prioritario:** la ficha abrirá `wa.me` con texto editable y referencia del vehículo. CocheMotor no pulsará «Enviar» ni transmitirá el mensaje automáticamente.
3. **PDF:** la acción abrirá la impresión nativa desde una composición preparada para guardar como PDF. El enlace público se incluirá como texto. Una descarga binaria automática y un QR quedan fuera de esta entrega porque el repositorio no dispone de generador local y no se han autorizado dependencias o servicios externos.
4. **Formulario existente:** la solicitud de contacto conserva sus campos y comportamiento; no se añade un campo libre ni nuevos datos personales en esta iniciativa.
5. **Redes sociales:** no se crearán publicaciones automáticas ni se conectarán cuentas. Las redes compatibles aparecerán en el selector nativo del dispositivo; copiar enlace queda siempre disponible.
6. **SEO y URL:** se mantiene la URL canónica que ya resuelva la ficha. Las fichas reales siguen sujetas a Spec 009; las demostrativas conservan su tratamiento no indexable.
